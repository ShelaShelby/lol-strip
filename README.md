# LoL Strip
Windows 11 x64, portable unsigned `lol-strip.exe`: a two-line taskbar strip (next two matches of LEC, LPL, LCK, LCS, CBLOL and all international events) plus a tray icon.
Run it once (it starts with Windows by default); right-click the tray icon for the next 12 matches, league toggles, notifications and "Open schedule".
If nothing shows, tray menu > "Run probe" (or `lol-strip.exe --probe`) and read `probe.txt` next to the exe.
